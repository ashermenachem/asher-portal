# Security Policy

## Reporting a vulnerability

Do not publish security vulnerabilities in a public issue.

Report suspected vulnerabilities privately to the repository owner through GitHub. Include:

- the affected version
- steps to reproduce
- expected and actual behavior
- the security impact
- any suggested fix

Please allow reasonable time for investigation before public disclosure.

## Security model

Asher Portal displays live websites through Chromium and runs a real local shell. It is not a sandbox for untrusted commands, a VPN, an anonymity product, or a tracking blocker.

Only open websites and run commands that you trust.
